# 新規CPUデッキ レシピ置き場

CPU対戦の相手デッキとして追加する、新しいデッキレシピ用の画像置き場です。
既存の `server/game/premade_decks.json`(第3弾〜第6弾、天草絵巻サイトの
デッキ紹介ページを元にしたもの)と同じ要領で、デッキリストの画像
(スクリーンショット等)を `images/` に入れておけば、実カードへマッピング
して `premade_decks.json` に追加できます。

## 使い方

1. `images/` フォルダに、追加したいデッキのカードリストが分かる画像
   (デッキレシピのスクリーンショット等)を入れる。
2. 準備ができたら「新しいデッキ画像を反映して」のように伝えてもらえれば、
   画像を確認して `premade_decks.json` に新しいデッキを追加します。

## 補足

- 追加されたデッキは、CPU対戦のランダム候補になります。デッキ編集画面の
  「おすすめデッキ」からプレイヤーが選べるようにするかどうかは、
  `premade_decks.json` の各デッキに付く `playerSelectable` フラグで
  制御しています(`false` を指定するとCPU専用になり、プレイヤーからは
  選べません。省略時は既存デッキ同様プレイヤーからも選択可能です)。
- 写真の解像度や画質の都合で判読が難しいカードは、デッキと同じ色の
  マリョク(または汎用の魔力ゾーン用カード)で代替していることがあります。
- `images/` 内の画像は2026/09時点で反映済みの分を含みます。新しい画像を
  追加した場合は、上記の手順で改めて伝えてください。

## 反映済みデッキ(2026/09時点、CPU専用)

`images/` に投入された10枚のスクリーンショット(1枚に2デッキ含むものを含む)
を確認し、以下の3デッキを新規にCPU専用デッキとして追加しました。

- `タマプラ(6弾)` — なちぞう選手の優勝デッキ(タマル王+プラトン)
- `司馬虎(6弾)` — モンT選手の優勝デッキ(司馬遷+小林虎三郎)
- `司馬遷家康(6弾)` — モンTサブ選手の優勝デッキ(司馬遷+徳川家康)
- `赤黄城壁リンボラース(6弾)` — 天草絵巻サイト「2nd2弾環境」ページ掲載の
  公式デッキレシピ(監修:ヨシタカ&かわけん、執筆:Ree、26/9付)。
  ジョージ・スチーブンソン/マシュー・カルブレイス・ペリーで「払暁の城壁」
  「ラース」「リンボ」を使い回しつつ手札を整え、最後はジャンヌ・ダルクの
  トリプルプレッシャーで決めるコントロール寄りのデッキ。既存の航海円形系
  ともペリーを共有するがコアエンジンが別物のため別デッキとして追加。

残りのデッキについては、以下の理由で見送りました。

- 「青緑円形」「藍色円形」「グラップラーペリー」「アークライトとクロン
  プトン」「ストウエンビー」「Hearth Stowe」系の各デッキは、既存の
  `航海円形`・`青紫航海円形`・`アークライトピラー`・`利休エンビー`・
  `ハースストウ` と中核カードが重複しており、「似たようなデッキ」に該当
  すると判断しました。
- 「リース家虎」「ちよこん」「ミミック」は、写真の解像度の都合でキーと
  なるイジンカードを確信を持って特定できなかったため見送りました。
