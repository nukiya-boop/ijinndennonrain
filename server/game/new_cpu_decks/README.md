# 新規CPUデッキ レシピ置き場

CPU対戦の相手デッキとして今後追加する予定の、新しいデッキレシピ用の
画像置き場です。既存の `server/game/premade_decks.json`(第3弾〜第6弾、
天草絵巻サイトのデッキ紹介ページを元にしたもの)と同じ要領で、デッキ
リストの画像(スクリーンショット等)を `images/` に入れておけば、後で
実カードへマッピングして `premade_decks.json` に追加できます。

## 使い方

1. `images/` フォルダに、追加したいデッキのカードリストが分かる画像
   (デッキレシピのスクリーンショット等)を入れる。
2. 準備ができたら「新しいデッキ画像を反映して」のように伝えてもらえれば、
   画像を確認して `premade_decks.json` に新しいデッキを追加します。

## 補足

- ここに置いた画像はまだゲームには反映されていません(反映は別途対応)。
- 追加されたデッキは、CPU対戦のランダム候補になります。デッキ編集画面の
  「おすすめデッキ」からプレイヤーが選べるようにするかどうかは、
  追加時に別途相談してください(既存のCPUデッキは現在プレイヤーからも
  選択可能になっています)。
