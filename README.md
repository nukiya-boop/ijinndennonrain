# イジンデン オンライン(非公式ファン制作)

ダイソーの100円TCG「イジンデン」のルールを元にした、ブラウザで遊べる1対1のオンライン対戦アプリです。
Node.js + Socket.io によるリアルタイム対戦と、一切ビルド不要のバニラJSフロントエンドで構成しています。

**本アプリはダイソー/株式会社大創産業/有限会社ワンドローとは一切関係のない、非公式のファン制作物です。**
公式サイト(one-draw.jp)で公開されているルールカード・ルール補足・カードリスト(第1弾)を参考にしていますが、
著作権保護されたイラストや商品名の商標的使用は含んでいません。

## 遊び方

```
npm install
npm start
```

`http://localhost:3000` を2つのブラウザタブ(または2台の端末)で開き、片方で「対戦部屋を作る」、
もう片方で発行された5文字の部屋コードを入力して「部屋に参加する」を押すと対戦が始まります。

## 実装しているルール

- デッキ40枚、同名カード最大4枚まで
- 準備: 手札6枚 + ガーディアン4枚(裏向き)
- ターン: スタート→ドロー→メイン→エンドの4フェイズ
- マリョク配置権/イジン召喚権(1/ターン、ハイケイ等での増加に対応)
- 魔力ゾーンのレベル条件・色条件、マホウの魔力コスト
- バトル: 複数ブロッカー対応、ダブル/トリプルプレッシャー、ウォッチャー、即応
- ガーディアンのブロック判定(アタッカーのパワーが0以下の時のみガーディアンが生還)
- 勝利条件: アタックが1体でも防がれなければ即勝利/相手が自分のターンを山札0枚で終えたら敗北(2025年エラッタ準拠)
- パワー0以下のイジンはアタッカー宣言不可(エラッタ準拠)
- 遺業能力のうち「Nドローする」「復元」「魔力化」を自動処理
- 全9種のマホウ(チャンピオン/ファイナルアタック/ストーム/リバイバル/エイジング/ロイヤリティ/デスペラード/ドローイング/ギャザリング)を個別実装

## カードデータについて

カード名・色・レベル・パワー・ルールテキストは、公式サイトで配布されているカードリスト(第1弾,
1stlist_230719.xlsx)を元にしています。デッキは各色(赤/青/緑)ごとに、公式カードのみを使って
自動生成される40枚のスターターデッキです(手動デッキ構築機能は今回のスコープ外)。

## スコープ外・簡略化している点

- イジン80種の個別テキストのうち、キーワード能力(即応/ダブル・トリプルプレッシャー/ウォッチャー/特性タグ)
  以外の固有能力は自動処理されません。カード詳細のモーダルにテキストは表示されるので、対戦者同士の合意で
  手動運用することは可能です。
- ハイケイ15種・マリョク15種のうち、効果が明確に自動処理できるもの(パワー付与オーラ、マリョク配置権+1、
  配置時ドロー、遺業能力の復元/魔力化)のみ実装しています。それ以外は設置・破壊等の基本動作のみで、
  固有テキストはフレーバーとして表示されるのみです。
- 装備(そうび)・木霊・冥府発動・反魂・スタンドなどの特殊システムは未実装です。
- マッチ戦・サイドデッキ・手札引き直しなどのオプションルールは未実装です。
- 切断時の再接続には対応していません(接続が切れると対戦相手に通知だけ行われます)。

## 構成

```
server/
  index.js        Express + Socket.io サーバー本体
  rooms.js         部屋管理・ソケットイベントの振り分け
  game/
    cards.js       カードマスタのロードとスターターデッキ生成
    cards_data.json 公式カードリスト(第1弾)から抽出したカードデータ
    engine.js      ルールエンジン(状態遷移・アクション処理)
    serialize.js   対戦相手に非公開情報を隠したクライアント向け状態生成
public/
  index.html / css/style.css / js/main.js   フロントエンド(バニラJS, ビルド不要)
```
